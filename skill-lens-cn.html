macOS Local App

SkillLens 中文技能图鉴

一款面向中文用户的 macOS 本地应用，用清晰的中文说明 Codex 已安装的 Skill，并把搜索、筛选、健康检查和调用示例放进同一个界面。

SwiftUI Local First 1.0.0 已验收
项目状态

应用、验证程序和 DMG 安装包已完成，本地交付通过。当前版本默认只读，不执行 Skill 脚本，也不修改原始文件。

Project Context

先解决“看不懂、找不到”

Skill 数量增加后，真正的成本不是安装，而是不知道每个 Skill 解决什么问题、什么时候该调用。

Problem

技能分散且说明偏技术

用户 Skill、项目 Skill 和插件 Skill 来自不同目录，英文说明和复杂结构增加了发现成本。

Solution

本地扫描与中文解读

统一扫描技能目录，补充中文用途、调用示例、依赖和健康状态，并支持全文搜索。

Boundary

只读优先

首次扫描只建立本地索引；只有用户主动确认后，才会把当前 Skill 文本发送给所选模型。

Delivery

从目录扫描做到可安装应用

项目不是界面原型，交付范围包含解析、搜索、生成、隐私边界、验证程序和安装包。

01

统一扫描

识别用户、Codex、插件和自定义目录，解析 Skill 及附带资源。

02

中文检索

支持中文关键词搜索英文 Skill，并按分类、来源和健康状态筛选。

03

本机生成

接入本机 Codex 或兼容 API，生成结构化中文用法并按内容哈希缓存。

04

打包验收

完成 Debug、Release、独立验证程序、签名结构和 DMG 完整性检查。
